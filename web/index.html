 THE TOOLCHAIN
One brief. A whole creative loop.
The workbench coordinates local tools and keeps each output reviewable.

        

          
01
✳
LOCAL LANGUAGE MODEL
Turn the idea into a world brief
The local planner develops the setting and encounter. A fixed seed controls the terrain shape independently of the text, so the same seed rebuilds the same surface and cave.
OUTPUT · world-spec.json

          
02
▦
PIXEL ART PIPELINE
Create a coherent tile set
A shared 16-pixel grid and bounded palette produce terrain tiles, player frames, and a cave enemy sheet. The workbench shows the world and art for review.
OUTPUT · TILE ATLAS · SPRITE SHEETS

          
03
◈
GODOT 2D RUNTIME
Make one complete sandbox slice
Connected chunks hold a side-scrolling surface and cave, player movement, mining, block placement, one tool recipe, one enemy, and local save/reload.
OUTPUT · GODOT PROJECT

          
04
◉
LOCAL VISUAL REVIEW
Inspect art without silent edits
The local vision model can comment on tile readability and sprite frames. Its report is advisory and never modifies generated assets.
OUTPUT · pixel-art-review.json

        

        
⌑
Local by design
The workbench and game generation stay on this Mac. The Godot project has no network dependencies. Godot 4.3+ is needed to run it; the workbench still shows the generated world and art sheets if Godot is absent.
